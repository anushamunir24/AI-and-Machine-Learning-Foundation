# DecodeLabs AI Internship Portfolio

Welcome to my central repository for the **DecodeLabs AI Industrial Training (Batch 2026)**. This portfolio contains all the foundational and advanced machine learning projects completed during the internship program.

---

## Repository Structure & Project Directory

Every project inside this repository is well-documented and contains its own dedicated application script along with an isolated `README.md` explaining its core logic and metrics.

🤖 [Project 1: Rule-Based AI Chatbot](./project1)
* **Description:** A deterministic conversation bot built using exact keyword-matching and Python dictionaries.
* **Key Focus:** String manipulation (`.lower()`, `.strip()`), conditional loops, and fallback exception handling.

🌸 [Project 2: Iris Flower Classification](./project2)
* **Description:** A classic Supervised Machine Learning pipeline classifying species using the K-Nearest Neighbors (KNN) algorithm.
* **Key Focus:** Data preprocessing (`StandardScaler`), splitting datasets, and metric evaluation (F1-score, Confusion Matrix).

🎬 [Project 3: AI Movie Recommendation Engine](./project3)
* **Description:** An NLP-powered content-based recommendation system that scores item descriptions against user query intents.
* **Key Focus:** Feature engineering, `TfidfVectorizer` (TF-IDF mapping), and `cosine_similarity` vector mechanics.
